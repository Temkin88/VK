### Установка зависимостей

```bash
venv .venv
source .venv/bin/activate
pip install -U pip
pip install -r requirements.txt
```

### Запуск

```bash
locust
```

Далее:
* Открываем ссылку из консоли
* Вводим в поле Host адрес нужного песка
* Указываем нужное количество пользователей и желаемые сценарии
* Запускаем
